快速上手

下载安装

macOS: 双击 DMG,拖入 Applications;Windows: 解压后运行 build.bat

授予权限

macOS: 系统设置 → 隐私与安全性 → 辅助功能 → 启用 KeyboardDrop;也可菜单栏点击「打开辅助功能设置」

配置映射

菜单栏点击键盘图标 → 设置... → 可视化编辑映射表格 → 保存并应用

查看教程

菜单栏 → 使用教程,打开完整帮助页面,包含配置格式、按键名参考、示例

配置示例

两种写法:字符串值 = 按键重映射;对象值 = 自定义操作(type + target)。配置文件在 macOS 为 ~/.keyboarddrop/config.json
{
  "mappings": {
    "caps_lock": "escape",
    "right_command": "left_control",
    "f5": { "type": "command", "target": "open -a 'Activity Monitor'" },
    "f6": { "type": "screenshot", "target": "region" },
    "f7": { "type": "volume", "target": "mute" },
    "f8": { "type": "media", "target": "play" },
    "f9": { "type": "system", "target": "lock" },
    "f10": { "type": "url", "target": "https://github.com" },
    "f11": { "type": "text", "target": "my-email@gmail.com" }
  }
}

常见问题

Q: 按下映射键没反应?

A: 检查辅助功能权限是否已授予。菜单栏 → 打开辅助功能设置,启用 KeyboardDrop。权限已开但仍无效,尝试「重载配置」。

Q: caps_lock 映射不稳定?

A: macOS 对 caps_lock 有特殊底层处理,CGEventTap 无法完美拦截。如需完美 caps_lock 映射,建议使用 Karabiner-Elements。

Q: 修改配置后如何生效?

A: 菜单栏 → 重载配置,或菜单栏 → 设置... → 保存并应用。两种方式都立即生效,无需重启。

Q: 如何切换中英文?

A: 菜单栏点击键盘图标 → 选择「Switch to English」或「切换为中文」即可切换界面语言。
